# Wiki server

MediaWiki 1.43 (LTS) + MariaDB 11.4, with Cargo, Page Forms and Approved Revs.

Files that live **only on the server** (never committed):

- `.env` – contains `DB_PASSWORD=...`
- `LocalSettings.php` – generated by the MediaWiki installer

## First deployment / update

On the server, the wiki lives in `~/wiki`.

1. Copy the files from this directory to the server (from the repository root):

   ```bash
   scp -P 2278 docker/Dockerfile docker/docker-compose.yml docker/LocalSettings.project.php ubuntu@152.66.245.139:~/wiki/
   ```

2. Once only: load the project settings from `LocalSettings.php` (on the server):

   ```bash
   grep -q LocalSettings.project.php ~/wiki/LocalSettings.php || echo 'require_once "$IP/LocalSettings.project.php";' >> ~/wiki/LocalSettings.php
   ```

3. Build and restart (on the server):

   ```bash
   cd ~/wiki && docker compose up -d --build --force-recreate
   ```

4. Create the database tables of the new extensions (on the server):

   ```bash
   docker compose exec mediawiki php maintenance/run.php update --quick
   ```

5. Check on the wiki: `Special:Version` should list Cargo, Page Forms and Approved Revs.
